## 27 Shortest Vector

The shortest vector problem is a central computational problem in the classical area of geometry of numbers. The approximation algorithm presented below has many applications in computational number theory and cryptography. Two of its most prominent applications are the derivation of polynomial time algorithms for factoring polynomials over the rationals and for simultaneous diophantine approximation.

Problem 27.1 (Shortest vector) Given n linearly independent vectors $\mathbf { a } _ { 1 } , \ldots , \mathbf { a } _ { n } \in \mathbf { Q } ^ { n }$ , find the shortest vector, in Euclidean norm, in the lattice generated by these vectors. The lattice L generated by $\pmb { a } _ { 1 } , \ldots , \pmb { a } _ { n }$ is the set of all integer linear combinations of these vectors, i.e., $\mathcal { L } = \{ \lambda _ { 1 } \pmb { a } _ { 1 } + . . . +$ $\lambda _ { n } { \pmb a } _ { n } \mid \lambda _ { i } \in { \bf Z } \}$

Remark 27.2 We will consider only full rank lattices, i.e., lattices that span the entire space on which they are defined. Most of the results apply to the general case as well, although the details can get more involved.

We will present an exponential (in n) factor algorithm for this problem. The problem of finding a polynomial factor algorithm for shortest vector has remained open for over two decades. It is worth pointing out that the exponential factor algorithm does perform well in practice and is widely used.

The shortest vector in the 1-dimensional lattice generated by two integers is simply the greatest common divisor (gcd) of these integers, which is polynomial time computable by Euclid’s algorithm. When restricted to two dimensions, the shortest vector problem is polynomial time solvable. This follows from an algorithm of Gauss that was originally formulated in the language of quadratic forms. It will be instructive to first study these two algorithms, since Gauss’ algorithm can be viewed as a generalization of Euclid’s algorithm, and the n-dimensional algorithm can be seen as a generalization of Gauss’ algorithm.

Several peculiarities set the shortest vector problem apart from other problems studied in this book. Unlike other NP-hard problems, we do not know if there is an instance of shortest vector that has exponentially many solutions, i.e., a lattice that has exponentially many shortest vectors. Indeed, this problem is not known to be NP-hard in the usual sense; it is only known to be NP-hard under randomized reductions. Another point of diference is that the lower bounding scheme used for obtaining the exponential factor algorithm can, in principle, be used to obtain a polynomial factor algorithm – by an existential argument we will prove that this scheme gives rise to a factor n approximate No certificate for the shortest vector problem. In contrast, for all other problems studied in this book, the best known lower bound is actually polynomial time computable.

## 27.1 Bases, determinants, and orthogonality defect

In this chapter all vectors will be assumed to be row vectors, unless otherwise stated. Let A denote the $n \times n$ matrix whose rows are the given vectors, $\mathbf { } a _ { 1 } , \ldots , \mathbf { } a _ { n }$ . Let vectors $b _ { 1 } , \dots , b _ { n } \in { \mathcal { L } }$ , and let B denote the n × n matrix whose rows are $b _ { 1 } , \ldots , b _ { n }$ . Since $\mathbf { } a _ { 1 } , \ldots , \mathbf { } a _ { n }$ can generate $b _ { 1 } , \dotsc , b _ { n } , B = A A$ • where Λ is an $n \times n$ integer matrix. Therefore det $( B )$ is an integer multiple of det(A). We will say that $b _ { 1 } , \ldots , b _ { n }$ form a basis for lattice $\mathcal { L }$ if the lattice generated by these vectors is precisely L. A square matrix with integer entries whose determinant is ±1 will be called unimodular. Observe that its inverse is also unimodular.

Theorem 27.3 Let vectors $b _ { 1 } , \dotsc , b _ { n } \in \mathcal { L }$ . The following conditions are equivalent:

1. $b _ { 1 } , \dots , b _ { n } \ f o r m \ a$ basis for lattice L

Hence, $\operatorname* { d e t } ( A ) \operatorname* { d e t } ( A ^ { \prime } ) = 1$ . By Theorem 27.3, the determinant of a basis for L is invariant, up to sign. We will call $| \mathrm { d e t } ( A ) |$ the determinant of lattice L and will denote it as det $\mathcal { L }$ Observe that det L is the volume of the parallelohedron defined by the basis vectors. Theorem 27.3 also tells us that we can move from basis to basis by applying unimodular transforms. We will use this fact in our algorithms.

The most desirable basis to obtain is an orthogonal basis, since it must contain a shortest vector of L (see Exercise 27.1). However, not every lattice admits such a basis. For instance, the following 2-dimensional lattice has no orthogonal basis. (The two shaded parallelohedra have volume det L each.)

We will denote the Euclidean norm of vector a by $\| a \|$ . Recall Hadamard’s inequality, which states that for an n × n real matrix A,

$$
| \det (\boldsymbol {A}) | \leq \| \boldsymbol {a} _ {1} \| \dots \| \boldsymbol {a} _ {n} \|.
$$

This inequality holds with equality if one of the rows of A is the zero vector or else the rows are mutually orthogonal. Applying this inequality we get that any basis $b _ { 1 } , \ldots , b _ { n }$ satisfies

$$
\det \mathcal {L} \leq \| \boldsymbol {b} _ {1} \| \dots \| \boldsymbol {b} _ {n} \|.
$$

Since none of the basis vectors is the zero vector, the inequality holds with equality if the basis is orthogonal. Let us define the orthogonality defect of basis $b _ { 1 } , \ldots , b _ { n }$ to be

$$
\frac {\| \boldsymbol {b} _ {1} \| \dots \| \boldsymbol {b} _ {n} \|}{\det \mathcal {L}}.
$$

Since det $\mathcal { L }$ is invariant, the smaller the orthogonality defect of a basis, the shorter its vectors must be.

Let us say that linearly independent vectors $b _ { 1 } , \dots , b _ { k } \in { \mathcal { L } }$ are primitive if they can be extended to a basis of L. For a single vector, primitivity is easy to characterize. Let us say that $\mathbf { \boldsymbol { a } } \in \mathcal { L }$ is shortest in its direction if xa is not a vector in L for $0 < | x | < 1$

Theorem 27.4 Vector $\mathbf { \boldsymbol { a } } \in \mathcal { L }$ is primitive if a is shortest in its direction.

Proof: Suppose there is a basis B of L containing a. Any vectors of the form xa, where x is a scalar, that can be generated using B must have $x \in \mathbf { Z }$ Therefore, a is shortest in its direction.

Suppose a is shortest its direction. Since $\mathbf { { \boldsymbol { a } } } \in { \mathcal { L } } $ , we can write

$$
\boldsymbol {a} = \lambda_ {1} \boldsymbol {a} _ {1} + \dots + \lambda_ {n} \boldsymbol {a} _ {n},
$$

where $\lambda _ { i } \in \mathbf { Z } ,$ and $\pmb { a } _ { 1 } , \ldots , \pmb { a } _ { n }$ form a basis for L. Since a is shortest in its direction, $\operatorname* { g c d } ( \lambda _ { 1 } , \ldots , \lambda _ { n } )$ is 1. Therefore, there exists a unimodular $n \times n$ matrix, say $\varLambda ,$ whose first row is $\lambda _ { 1 } , \ldots , \lambda _ { n }$ (see Exercise 27.2). Let $B = A A$ By Theorem 27.3, B is a basis for ${ \mathcal { L } } .$ Since the first row of B is $\mathbf { \delta } _ { \mathbf { a } , \mathbf { \delta } }$ , the theorem follows. ✷

## 27.2 The algorithms of Euclid and Gauss

In one dimension the lattice generated by basis vector a is simply all integer multiples of $\mathbf { \delta } _ { \mathbf { a } , \mathbf { \delta } }$ . Hence, the shortest vector problem is trivial in the 1-dimensional case. Instead, consider the following problem. Given integers a and $b ,$ consider all integer linear combinations of a and $b ,$ and find the smallest number in this lattice. This will be the gcd of a and $b ,$ denoted by $( a , b )$

Assume w.l.o.g. that $a \geq b \geq 0$ . The idea behind Euclid’s algorithm is that since $( a , b ) = ( a - b , b )$ , we can replace the original problem by a smaller one. Continuing in this manner we are left with finding the smallest number, in absolute value, in the sequence $\{ | a - m b |$ , for $m \in \mathbf { Z } \}$ . Let this be c. If $c = 0$ ， then $( a , b ) = b ,$ and we are done. Otherwise, $( a , b ) = ( b , c )$ , and we proceed with the pair $b , c .$ Observe that $c \leq b / 2$ . Hence this process terminates in $\log _ { 2 } b$ iterations.

Next, let us present Gauss’ algorithm in 2 dimensions. For this case, a weaker condition than orthogonality is suficient for ensuring that a basis contains a shortest vector. Let θ denote the angle between basis vectors $b _ { 1 }$ and $b _ { 2 } , 0 ^ { \circ } < \theta < 1 8 0 ^ { \circ }$ . Thus, det $\mathcal { L } = \| b _ { 1 } \| \cdot \| b _ { 2 } \|$ sin θ. Number the vectors so that $\left\| \pmb { b } _ { 1 } \right\| \leq \left\| \pmb { b } _ { 2 } \right\|$

Theorem 27.5 $I f 6 0 ^ { \circ } \leq \theta \leq 1 2 0 ^ { \circ }$ , then $b _ { 1 }$ is a shortest vector in lattice $\mathcal { L }$

Proof: Assume for the purpose of contradiction that there is a vector $\pmb { b } \in \mathcal { L }$ that is shorter than $b _ { 1 } .$ Since $\mathbf { b } _ { 1 }$ and $b _ { 2 }$ are both primitive, b cannot be linearly dependent on $b _ { 1 }$ or $b _ { 2 }$ . By a simple case analysis it is easy to see that b must form an angle of at most $6 0 ^ { \circ }$ with one of $b _ { 1 } , b _ { 2 } , - b _ { 1 } , \mathrm { o r } - b _ { 2 }$

![](images/acbc3b617682eada2ddb51c3c40fd32f9e1943b1bd63aa73ef18bf6323dc7169.jpg)  
Let D be the $2 \times 2$ matrix whose rows consist of this vector and b. Observe that $| \mathrm { d e t } ( \boldsymbol { D } ) |$ is nonzero and is strictly smaller than det $\mathcal { L } = \left\| \boldsymbol { b } _ { 1 } \right\| \cdot \left\| \boldsymbol { b } _ { 2 } \right\|$ sin $\theta .$ This contradicts the fact that det $( D )$ is an integer multiple of det $\mathcal { L }$ . Hence $\mathbf { { b } } _ { 1 }$ is a shortest vector in ${ \mathcal { L } } .$ ✷

Define

$$
\mu_ {2 1} = \frac {\pmb {b} _ {2} \cdot \pmb {b} _ {1}}{\| \pmb {b} _ {1} \| ^ {2}},
$$

where · represents inner product. Observe that $\mu _ { 2 1 } b _ { 1 }$ is the component of $b _ { 2 }$ in the direction of $\mathbf { b } _ { 1 }$ . The following proposition suggests an algorithm for finding a basis satisfying the condition of Theorem 27.5.

Proposition 27.6 If basis $\left( b _ { 1 } , b _ { 2 } \right)$ satisfies

$\left\| \pmb { b } _ { 1 } \right\| \leq \left\| \pmb { b } _ { 2 } \right\|$ and

$| \mu _ { 2 1 } | \leq 1 / 2$

Clearly, after step $2 ( \mathrm { a } )$ is performed, $| \mu _ { 2 1 } | \leq 1 / 2$ . Observe that the operation in this step is quite similar to that in Euclid’s gcd algorithm. Since $\left\| \boldsymbol { b } _ { 1 } \right\| \cdot \left\| \boldsymbol { b } _ { 2 } \right\|$ decreases after each iteration, the algorithm must terminate (there are only a bounded number of vectors of $\mathcal { L }$ within a given radius). ## 27.3 Lower bounding OPT using Gram–Schmidt orthogonalization

In this section we will present the Gram–Schmidt lower bound on OPT, the length of a shortest vector in lattice ${ \mathcal { L } } .$

Intuitively, the Gram–Schmidt orthogonalization of basis $b _ { 1 } , \ldots , b _ { n }$ gives the n “altitudes” of the parallelohedron defined by this basis. Formally, it is a set of mutually orthogonal vectors $b _ { 1 } ^ { * } , \ldots , b _ { n } ^ { * }$ , where $b _ { 1 } ^ { * } = b _ { 1 }$ and ${ b } _ { i } ^ { * }$ is the component of $\mathbf { } _ { b _ { i } }$ orthogonal to $b _ { 1 } ^ { * } , \ldots , b _ { i - 1 } ^ { * } , { \mathrm { f o r ~ } } 2 \leq i \leq n . \ : b _ { i } ^ { * }$ can be obtained from $\mathbf { } _ { b _ { i } }$ by subtracting from it components in the directions of $b _ { 1 } ^ { * } , \ldots , b _ { i - 1 } ^ { * } ,$ as given by the following recurrence:

$$
\boldsymbol {b} _ {1} ^ {*} = \boldsymbol {b} _ {1}
$$

$$
\boldsymbol {b} _ {i} ^ {*} = \boldsymbol {b} _ {i} - \sum_ {j = 1} ^ {i - 1} \frac {\boldsymbol {b} _ {i} \cdot \boldsymbol {b} _ {j} ^ {*}}{\| \boldsymbol {b} _ {j} ^ {*} \| ^ {2}} \boldsymbol {b} _ {j} ^ {*}, i = 2, \dots , n.\tag{27.1}
$$

![](images/52b104347e5f9597db50144354698e339109e055efd981c6379e816192db5291.jpg)

For $1 \leq j < i \leq n .$ , define

$$
\mu_ {i j} = \frac {\boldsymbol {b} _ {i} \cdot \boldsymbol {b} _ {j} ^ {*}}{\| \boldsymbol {b} _ {j} ^ {*} \| ^ {2}},
$$

and define $\mu _ { i i } = 1$ . Then

$$
\boldsymbol {b} _ {i} = \sum_ {j = 1} ^ {i} \mu_ {i j} \boldsymbol {b} _ {j} ^ {*}, i = 1, \dots , n.\tag{27.2}
$$

For $j \leq i ,$ define ${ \pmb b } _ { i } ( j )$ to be the component of $b _ { i }$ orthogonal to $b _ { 1 } , \dotsc , b _ { j - 1 }$ i.e.,

$$
\boldsymbol {b} _ {i} (j) = \mu_ {i j} \boldsymbol {b} _ {j} ^ {*} + \mu_ {i, j + 1} \boldsymbol {b} _ {j + 1} ^ {*} + \dots + \boldsymbol {b} _ {i} ^ {*}.
$$

It is easy to see that

$$
\det \mathcal {L} = \| \boldsymbol {b} _ {1} ^ {*} \| \dots \| \boldsymbol {b} _ {n} ^ {*} \|.
$$

Therefore, the orthogonality defect of this basis can be written as

$$
\frac {\| \boldsymbol {b} _ {1} \| \ldots \| \boldsymbol {b} _ {n} \|}{\| \boldsymbol {b} _ {1} ^ {*} \| \ldots \| \boldsymbol {b} _ {n} ^ {*} \|} = \frac {1}{\sin \theta_ {2} \ldots \sin \theta_ {n}},
$$

where $\theta _ { i }$ is the angle between $\mathbf { } _ { b _ { i } }$ and the vector space spanned by $b _ { 1 } , \dotsc , b _ { i - 1 }$ for $2 \leq i \leq n$ . This angle is defined as follows. Let $ { \boldsymbol { b } } _ { i } ^ { \prime }$ be the projection of $b _ { i }$ onto the space spanned by $b _ { 1 } , \dotsc , b _ { i - 1 }$ . Then

$$
\theta_ {i} = \cos^ {- 1} \left(\frac {\| \boldsymbol {b} _ {i} ^ {\prime} \|}{\| \boldsymbol {b} _ {i} \|}\right).
$$

Notice that the Gram–Schmidt orthogonalization depends not only on the basis chosen, but also on the ordering chosen among the basis vectors. It provides a lower bound on $\mathrm { O P T }$ as follows.

Lemma 27.8 Let $b _ { 1 } , \ldots , b _ { n }$ be a basis for lattice $\mathcal { L } ,$ and $b _ { 1 } ^ { * } , \ldots , b _ { n } ^ { * }$ be the Gram–Schmidt orthogonalization for it. Then

$$
\mathrm{OPT} \geq \min \{\| \boldsymbol {b} _ {1} ^ {*} \|, \dots , \| \boldsymbol {b} _ {n} ^ {*} \| \}.
$$

Proof: Let v be a shortest vector in $\mathcal { L } .$ Suppose $k$ is the largest indexed basis vector used in generating $_ { v , }$ i.e.,

$$
\boldsymbol {v} = \sum_ {i = 1} ^ {k} \lambda_ {i} \boldsymbol {b} _ {i},
$$

where $\lambda _ { k } \neq 0$ . Using (27.2), v can also be expressed as a linear combination of the vectors $\boldsymbol { b } _ { 1 } ^ { * } , \ldots , \boldsymbol { b } _ { k } ^ { * }$ . In this combination, the coeficient of $b _ { k } ^ { * }$ is $\lambda _ { k }$ , since $\mu _ { k , k } = 1$ . Since the vectors $b _ { 1 } ^ { * } , \ldots , b _ { n } ^ { * }$ are orthogonal,

$$
\left\| \boldsymbol {v} \right\| ^ {2} \geq \lambda_ {k} ^ {2} \left\| \boldsymbol {b} _ {k} ^ {*} \right\| ^ {2} \geq \left\| \boldsymbol {b} _ {k} ^ {*} \right\| ^ {2}.
$$

Hence

$$
\mathrm{OPT} = \| \boldsymbol {v} \| \geq \| \boldsymbol {b} _ {k} ^ {*} \| \geq \min \{\| \boldsymbol {b} _ {1} ^ {*} \|, \dots , \| \boldsymbol {b} _ {n} ^ {*} \| \}.
$$

## 27.4 Extension to n dimensions

In this section we will extend Gauss’ 2 dimensions algorithm to n dimensions. As usual, our main efort will be on improving the lower bound on $\mathrm { O P T }$ Recall that for any basis, $b _ { 1 } , \ldots , b _ { n }$ 2

$$
\| \boldsymbol {b} _ {1} ^ {*} \| \dots \| \boldsymbol {b} _ {n} ^ {*} \| = \det \mathcal {L}
$$

is an invariant, and min $\{ \| \pmb { b } _ { 1 } ^ { * } \| , \dots , \| \pmb { b } _ { n } ^ { * } \| \}$ is a lower bound on $\mathrm { O P T }$ . In a typical basis, the minimum will be attained towards the end of the sequence $\| \pmb { b } _ { 1 } ^ { * } \| , \ldots , \| \pmb { b } _ { n } ^ { * } \|$ . We will try to make this sequence lexicographically small, thereby ensuring that the last entries, and hence the minimum, are not too small. The conditions in Proposition 27.6 suggest a way of accomplishing this. By the first condition we have

$$
\left\| \boldsymbol {b} _ {1} \right\| ^ {2} \leq \left\| \boldsymbol {b} _ {2} \right\| ^ {2}, \text {i.e.,} \left\| \boldsymbol {b} _ {1} ^ {*} \right\| ^ {2} \leq \mu_ {2 1} ^ {2} \left\| \boldsymbol {b} _ {1} ^ {*} \right\| ^ {2} + \left\| \boldsymbol {b} _ {2} ^ {*} \right\| ^ {2}.
$$

Substituting for $\mu _ { 2 1 }$ from the second condition, we get

$$
\left\| \boldsymbol {b} _ {1} ^ {*} \right\| ^ {2} \leq \frac {1}{4} \left\| \boldsymbol {b} _ {1} ^ {*} \right\| ^ {2} + \left\| \boldsymbol {b} _ {2} ^ {*} \right\| ^ {2}
$$

Therefore,

$$
\| \boldsymbol {b} _ {1} ^ {*} \| \leq \frac {2}{\sqrt {3}} \| \boldsymbol {b} _ {2} ^ {*} \|.
$$

Thus ${ b } _ { 2 } ^ { * }$ cannot be smaller than $b _ { 1 } ^ { * }$ by more than a factor of $2 / { \sqrt { 3 } } .$ . Let us impose similar conditions on each consecutive pair of basis vectors, so that for each $i , b _ { i + 1 } ^ { * }$ is not smaller than ${ b } _ { i } ^ { * }$ by more than a factor of $2 / \sqrt { 3 }$ Then the first vector, $b _ { 1 }$ , will be within an exponential factor of the lower bound. Algorithm 27.7 extends in a natural way to iteratively ensuring all these conditions. However, we do not know how to establish termination for this extended algorithm (see Exercise 27.7 for details).

To ensure termination in a polynomial number of iterations, we will use an idea similar to that in Exercise 27.3. Let us say that basis $b _ { 1 } , \ldots , b _ { n }$ is Gauss reduced if, for $1 \leq i \leq n - 1$

$\begin{array} { r } { \| \pmb { b } _ { i } ( i ) \| \le \frac { 2 } { \sqrt { 3 } } \ \| \pmb { b } _ { i + 1 } ( i ) \| } \end{array}$

$| \mu _ { i + 1 , i } | \leq 1 / 2 .$

The algorithm for obtaining a Gauss reduced basis is a simple generalization of Algorithm 27.7.

<div class="mineru-algorithm" style="white-space: pre-wrap; font-family:monospace;">
Algorithm 27.9 (Shortest vector algorithm)
1. While basis  $b_{1},\ldots,b_{n}$  is not Gauss reduced, do:
(a) For each  $i,1\leq i\leq n-1$ , ensure that  $|\mu_{i+1,i}|\leq1/2$ .
If  $|\mu_{i+1,i}|&gt;1/2$  then  $b_{i+1}\leftarrow b_{i+1}-mb_{i}$ , where m is the integer closest to  $\mu_{i+1,i}$ .
(b) Pick any i such that  $\|b_{i}\|&gt;\frac{2}{\sqrt{3}}\|b_{i+1}\|$ , and interchange  $b_{i}$  and  $b_{i+1}$ .
2. Output  $b_{1}$ .
</div>

Theorem 27.10 Algorithm 27.9 terminates in a polynomial number of iterations and achieves an approximation guarantee of $2 ^ { ( n - 1 ) / 2 }$

Proof: For $1 \leq i \leq n - 1$ we have

$$
\begin{array}{l} \| \boldsymbol {b} _ {i} (i) \| ^ {2} = \| \boldsymbol {b} _ {i} ^ {*} \| ^ {2} \leq \frac {4}{3}   \| \boldsymbol {b} _ {i + 1} (i) \| ^ {2} = \frac {4}{3} (\mu_ {i + 1, i} ^ {2}   \| \boldsymbol {b} _ {i} ^ {*} \| ^ {2} + \| \boldsymbol {b} _ {i + 1} ^ {*} \| ^ {2}) \\ \quad \leq \frac {4}{3}   (\frac {1}{4}   \| \boldsymbol {b} _ {i} ^ {*} \| ^ {2} + \| \boldsymbol {b} _ {i + 1} ^ {*} \| ^ {2}). \end{array}
$$

Therefore,

$$
\| \boldsymbol {b} _ {i} ^ {*} \| ^ {2} \leq 2 \| \boldsymbol {b} _ {i + 1} ^ {*} \| ^ {2}.\tag{27.3}
$$

and so

$$
\| \boldsymbol {b} _ {1} \| \leq 2 ^ {(n - 1) / 2} \min _ {i} \{\| \boldsymbol {b} _ {i} ^ {*} \| \} \leq 2 ^ {(n - 1) / 2} \text {   OPT. }
$$

In order to show termination in a polynomial number of iterations, we will use the following potential function.

$$
\varPhi = \prod_ {i = 1} ^ {n} \| \boldsymbol {b} _ {i} ^ {*} \| ^ {(n - i)}.
$$

Notice that step $1 ( \mathrm { a } )$ in Algorithm 27.9 does not change the Gram–Schmidt orthogonalization of the basis and can be executed in $O ( n )$ arithmetic operations (each addition, subtraction, multiplication, and division counts as one operation). In an iteration, at most one interchange of vectors is performed in Step 1(b). If this happens, Φ drops by a factor of at least $2 / { \sqrt { 3 } }$ . Indeed this was the reason to introduce the factor of $2 / \sqrt { 3 }$ in the definition of a Gauss reduced basis. Let us assume w.l.o.g. that the initial basis has integer components. Then, the initial value of $\varPhi$ is at most

$$
\left(\max _ {i} \left\| \boldsymbol {a} _ {i} \right\|\right) ^ {n (n - 1) / 2}.
$$

We will show that $\varPhi \geq 1$ throughout the execution of the algorithm. Consequently, if the number of iterations is $m$ , then

$$
\left(\frac {2}{\sqrt {3}}\right) ^ {m} \leq (\max _ {i} \| \boldsymbol {a} _ {i} \|) ^ {n (n - 1) / 2}.
$$

Therefore,

$$
m \leq \frac {n (n - 1) \max _ {i} \log \| \boldsymbol {a} _ {i} \|}{2 \log (2 / \sqrt {3})}.
$$

Another motivation for defining the stronger notion of a Lov´asz reduced basis is that its orthogonality defect can also be bounded. ## 27.5 The dual lattice and its algorithmic use

## 27.7 Notes

Algorithm 27.9 and Theorem 27.11 are due to Lenstra, Lenstra, and Lov´asz [183]. Schnorr [235] modified this algorithm to achieve an approximation factor of $( 1 + \varepsilon ) ^ { n }$ , for any $\varepsilon > 0$ . More precisely, Schnorr’s algorithm runs in polynomial time for a suitable choice of $\varepsilon = o ( 1 )$ , which results in a slightly subexponential factor algorithm, i.e., an algorithm with an approximation factor of $2 ^ { o ( n ) }$ . This is currently the best approximation guarantee known for shortest vector.

Algorithm 27.7 appears in Gauss [99], though it is stated there in terms of quadratic forms. Using a complex potential function argument, Lagarias [180] showed that this algorithm has polynomial running time (in the number of bits needed to write the input basis). For a polynomial time algorithm for shortest vector in d-dimensions, for fixed constant d, see Kannan [154]. Example 27.12 is due to Kannan [153]. Ajtai [2] showed that the shortest vector problem is NP-hard under randomized reductions. Theorem 27.19 is due to Lagarias, Lenstra, and Schnorr [181].
