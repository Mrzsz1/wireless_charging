# 语义模型缓存目录与部署检查

## Goal

让用户在桌面设置中自定义本地语义模型及其派生缓存的存放目录，并能明确检查当前模型是否真正部署完成，而不是通过“目录存在”推断可用。

## Background

- 当前语义缓存路径硬编码为 `%LOCALAPPDATA%/LunaWiki/fastembed`，实现位于 `apps/desktop/src-tauri/src/qa/semantic.rs:335`。
- 当前进程以 `OnceLock<Mutex<SemanticState>>` 复用已加载模型；路径切换必须显式失效内存中的模型与语料缓存。
- Windows ONNX Runtime 已使用下载包 SHA-256、临时文件和原子重命名保护；fastembed/Hugging Face 使用 `.part` 表示未完成下载。
- 当前 `LunaSettings` 保存在知识库 SQLite 且要求先选择知识库。语义模型缓存属于本机共享资源，不应随知识库切换而改变。
- 设置页已有原生目录选择能力（`rfd::FileDialog`）和统一状态卡片样式，可复用现有交互模式。

## Requirements

- R1：提供全局、本机级语义缓存目录设置；未配置时保持现有默认目录。
- R2：目录设置在未选择知识库时仍可读取和修改，不写入知识库 SQLite。
- R3：保存路径前验证绝对路径、目录可创建/可读写，拒绝文件路径和明显无效路径。
- R4：设置页提供原生目录选择器、恢复默认路径、打开目录和保存能力。
- R5：提供不联网的部署检查，区分 `missing`、`partial`、`invalid`、`ready` 和 `error`。
- R6：部署检查覆盖 ONNX Runtime、量化多语言模型文件、tokenizer 配置、`.part` 状态，并实际加载模型执行一次 384 维有限数值探针。
- R7：提供显式“下载/修复”操作；只有该操作允许联网，普通状态刷新不得触发模型下载。
- R8：目录切换后安全失效进程内模型/语料状态；后续问答从新目录加载。
- R9：模型下载失败继续按现有 fail-soft 契约降级为其他检索通道，不阻断问答。
- R10：状态 DTO 不暴露用户文档内容、查询文本、凭据或远程响应正文。

## Acceptance Criteria

- [ ] 用户可在设置页选择并保存自定义缓存目录，重启应用后仍保持。
- [ ] 未选择知识库时仍可查看目录和部署状态。
- [ ] 完整模型通过探针后显示“已部署”；仅有 `.part` 时显示“下载未完成”。
- [ ] 缺少或损坏任一必需文件时不会误报 ready。
- [ ] “检查部署”断网时可正常完成且不发起下载。
- [ ] “下载/修复”可安装缺失资源，完成后重新检查并显示 ready。
- [ ] 路径切换不会继续复用旧目录中的内存模型或旧语料向量。
- [ ] 原有默认路径用户无需迁移即可继续使用。
- [ ] Rust、前端测试/构建和 Tauri release 编译通过。

## Out of Scope

- 支持用户选择任意第三方 embedding 模型。
- 自动删除旧模型目录或用户未确认的数据。
- 将语义模型配置做成知识库级设置。

## Product Decisions

- 路径切换不自动移动或删除数据。设置页提供两个显式操作：
  - “复制现有缓存并切换”：逐文件临时写入并重命名到新目录，切换成功后保留旧目录作为回滚副本。
  - “切换并重新部署”：先保存新目录，再由用户明确触发下载/修复；旧目录保持不变。
- “检查部署”严格离线；“下载/修复”是唯一允许联网获取模型资源的操作。
