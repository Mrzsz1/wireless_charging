# 左侧搜索与新建问答入口

## Goal

参照 Codex 的左侧命令区，将全局搜索与“新建问答”从内容区顶部移动到左侧栏，使页面正文获得更多垂直空间，并删除重复的刷新及研究脉络折叠入口。

## Requirements

1. 左侧栏展开状态下，在品牌/导航区域顶部提供全局搜索控件与“新建问答”入口，视觉层级和图 2 一致：搜索在上，新建问答紧随其下。
2. 搜索保留现有草稿、Enter 提交、明确搜索按钮、清空、忙碌状态、`Ctrl+K` 聚焦、最新请求守卫和自动进入文献库结果页行为。
3. 左侧栏折叠状态仍保留可识别的搜索与新建问答图标；搜索入口能够展开侧栏并聚焦输入框。
4. “新建问答”继续导航到智能问答页面，不新增重复状态或第二套搜索实现。
5. 删除内容区顶部工作区工具条；删除其中的知识库刷新按钮和研究脉络折叠按钮。
6. 研究脉络面板继续显示，其内部已有操作不受影响；仅删除顶部冗余折叠入口。
7. 顶部通知、页签、文献库搜索、分页以及其他页面导航不发生回归。
8. 1366×768 与 1920×1080 下无新增横向溢出，左侧栏滚动和折叠行为正常。
9. 不修改 Wiki、Raw 或 Graphify 内容；两个用户 Raw 运行目录保持未跟踪。

## Acceptance Criteria

- [x] AC1：全局搜索与新建问答在左侧栏顶部显示，内容区不再显示原工具条。
- [x] AC2：搜索按钮和 Enter 均可提交，Ctrl+K 可展开左栏并聚焦搜索框，清空和旧请求保护正常。
- [x] AC3：折叠侧栏仍可通过图标搜索和新建问答。
- [x] AC4：顶部刷新与研究脉络折叠按钮已删除，研究脉络面板仍正常显示。
- [x] AC5：Node 回归测试、前端构建、结构验证和严格 GUI E2E 通过。
- [x] AC6：Git 提交仅包含本任务文件，不包含两个 Raw 运行目录。
