# 设置集中管理与列表分页

## Goal

把自动文献检索的长期配置从“文献入库 → 自动添加”工作页迁移到统一“设置”页面，并允许用户在客户端安全配置论文搜索服务 API Key；同时为文献库与方法库的长列表提供稳定分页，避免几十条页面一次性纵向堆叠。

## Background

- 当前 `LiteratureIngestView` 同时承担运行监控与配置编辑，自动设置卡片挤压自动运行区，并造成明显横向拥挤。
- 当前“设置”页只是 `App.tsx` 内的占位式面板，尚未承担文献自动化配置。
- 搜索服务读取 `OPENALEX_API_KEY`、`TAVILY_API_KEY`、`SERPAPI_API_KEY` 或外部 Key 文件；客户端没有配置入口。SerpApi 实际用于 Google Scholar 检索。
- 文献库和方法库共用 `LibraryView`，现有实现一次渲染全部筛选结果；当前知识库已有 66 个页面。
- 两个自动检索失败运行目录属于用户数据，保持未跟踪，不修改、不删除、不提交。

## Requirements

### R1. 自动化配置迁入设置页

- “设置”新增“文献自动化”区域，管理启动询问、允许自动完整入库、相关度阈值、单次最大入库数、起始年份和启用的检索源。
- 设置仍按当前知识库路径保存在既有 SQLite 表中，仓库切换后显示对应仓库配置。
- 未选择知识库时该区域显示明确禁用状态，不伪造保存成功。
- 保存前端与 Rust 继续执行现有阈值、数量和检索源校验。
- “自动添加”页只保留运行摘要、立即执行、资格边界、依赖检查、运行日志和最近运行时间，并提供“前往设置”入口。

### R2. 搜索 API Key 安全配置

- “设置”新增“论文搜索服务”区域，展示 arXiv、OpenAlex、Tavily、Google Scholar（SerpApi）。
- arXiv 明确标记为无需 Key；其余三项显示已配置/未配置状态。
- 用户可输入新 Key、显示/隐藏本次输入、保存、清除，并可执行连接测试。
- Key 使用 Windows Credential Manager 保存；不得进入 SQLite、前端持久状态、任务参数、manifest、日志、错误文本、Git 或缓存键。
- 从安全存储读取的 Key 仅在启动 discovery/literature Python 子进程时注入对应环境变量；原有环境变量与外部 Key 文件仍作为兼容回退。
- 空输入不得覆盖已有 Key；清除必须显式操作。界面永不回显完整已保存 Key。
- 连接测试不得在错误信息或 URL 中暴露 Key。

### R3. 文献库与方法库分页

- `LibraryView` 对筛选后的最终列表分页，因此文献库、方法库、全局搜索结果都获得一致行为。
- 默认每页 10 条，并支持 10、20、50 条切换；显示总条数、当前范围、当前页/总页数、上一页、下一页和有限页码按钮。
- 查询词、页面类型、年份、状态、排序或每页数量变化时回到第一页。
- 结果数量减少导致当前页越界时自动限制到最后有效页；空结果稳定显示空状态而不是“第 1/0 页”。
- 分页只改变客户端可见切片，不改变后端搜索上限、BM25 排序或目录排序。
- 分页控件支持键盘操作、禁用边界按钮并提供可访问标签。

### R4. 兼容与质量

- 启动询问继续读取相同文献设置；“立即检索”继续按最新已保存配置运行。
- API Key 注入不得改变命令 allowlist、参数审计、日志脱敏、取消或重试语义。
- 设置页在 1366×768 和 1920×1080 下可滚动、无横向溢出；自动添加页移除右侧配置卡后使用单栏布局。
- 增加分页纯函数测试、设置状态测试、Rust 安全存储/注入测试、结构门禁和严格 GUI 路径。
- 版本提升到 0.10.0，重新构建 release、MSI、NSIS，并使用 Git 保存。

## Acceptance Criteria

- [x] AC1 / R1：自动配置仅在设置页可编辑；自动添加页不再显示右侧配置表单且仍可运行任务。
- [x] AC2 / R1：切换知识库后设置页加载对应配置，保存后重新进入页面值保持一致。
- [x] AC3 / R2：OpenAlex、Tavily、SerpApi Key 可保存、识别、测试和清除；已保存 Key 从不回显。
- [x] AC4 / R2：搜索任务子进程获得所需 Key 环境变量，而数据库、manifest、任务参数、日志和 Git diff 中没有 Key 明文。
- [x] AC5 / R2：arXiv 显示无需 Key；Google Scholar 明确标注由 SerpApi 提供。
- [x] AC6 / R3：66 条列表默认分页，上一页/下一页、页码和 10/20/50 每页切换正确。
- [x] AC7 / R3：搜索、筛选、排序、页面类型和每页数量变化重置第一页；越界页自动收敛。
- [x] AC8 / R4：前端测试/构建、Rust fmt/clippy/test、Python 测试、Wiki/Core-book 门禁、严格 GUI 与安装生命周期通过。
- [x] AC9 / R4：0.10.0 EXE/MSI/NSIS 生成并记录 SHA-256；用户 raw 失败目录未进入提交。

## Out of Scope

- 新增论文搜索提供商、改变打分算法或扩大自动入库权限。
- 把 Luna/MinerU 密钥一并迁入 Windows Credential Manager。
- 后端 SQL 游标分页；当前数据量使用前端分页，后端检索契约保持不变。
- 删除旧环境变量/Key 文件兼容路径。
