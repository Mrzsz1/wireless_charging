# 修复语义模型降级与中文近义零召回

## Goal

修复知识库实际存在波干涉论文、但用户询问“波干扰”时返回零证据的问题，并让同类中文近义/一字差异查询具备通用召回能力。

## Confirmed root cause

- 最新失败轮使用 `semantic-facet-rrf-v4`，但证据数为 0。
- 本地 `multilingual-e5-small` 只留下 394 MB `.part`，模型未完成，语义通道降级。
- 模型初始化失败被进程级永久记忆，后续提问不会重试。
- Planner 失败或空扩展被静默降级，审计清单看不到 Planner 状态。
- 通用中文切片只有 3–4 字，“波干扰”与库内“波干涉”缺少可连接的二字前缀“波干”。

## Requirements

- 改用更小的量化多语言本地模型，降低首次下载失败率。
- 模型初始化失败使用有界退避重试，不得在整个进程内永久禁用。
- 中文基线加入通用二字切片与停用片段过滤，不得新增“波干扰”专用映射。
- Planner 状态进入 RetrievalQuery/运行清单，区分成功、无 Provider、失败降级。
- 精确问题“有没有波干扰的论文”在不启用语义模型的测试环境中仍至少召回库内 Wiki 证据；带计划时召回可定位 primary paper。

## Acceptance Criteria

- [ ] 无任何波干扰专用别名仍可召回相关证据。
- [ ] 本地模型由 394 MB E5 改为较小量化多语言模型。
- [ ] 初始化失败会在退避期后重试。
- [ ] 审计记录包含 Planner 状态。
- [ ] Rust 全测、前端全测/构建、Tauri release 编译通过。
