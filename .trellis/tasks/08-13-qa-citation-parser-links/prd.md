# 修复句末引用解析与紧凑超链接展示

## Goal

修复事实句末标点后紧邻引用被错误拆分的问题，并让用户可见的证据入口以紧凑超链接呈现，不暴露冗长本地原文路径。

## Requirements

- `事实。[E1] [E2]`、`事实。 [E1]`、`事实。（[E1]）` 中的紧邻引用归属于前一事实声明。
- 空行、独立“参考来源”段落中的引用不得跨段继承。
- 保持未知引用、Graphify-only、代码/数学/Markdown 链接屏蔽规则不变。
- 回答中的 `[E#]` 使用真实可访问的紧凑超链接语义，点击后打开对应来源。
- 证据详情不直接显示冗长 `sourcePath`/`markdownPath`，改为短标签来源链接。
- 不改变审计包中的完整路径和证据元数据。

## Acceptance Criteria

- [x] 审计包中的自然句末引用格式不再产生 28/29 误判。
- [x] 独立引用段落仍不支撑上一段事实。
- [x] `[E#]` 在 UI 中是键盘可聚焦的链接，显示文本保持简短。
- [x] 点击 `[E#]` 可打开对应 Wiki、论文或书籍来源。
- [x] 页面不展示冗长本地原文路径，审计数据仍完整保留。

## Constraints

- 用户要求本轮不执行全量测试；仅做格式检查和定向静态验证。
- 不实现引用语义蕴含。
