# 单视图导航与问答右栏布局修复

## Goal

把客户端从“侧栏导航 + 工作区标签”双重导航改为侧栏驱动的单视图界面，并解决智能问答页被全局研究脉络挤压的问题。

## Requirements

1. 删除主工作区顶部标签栏；用户点击左侧导航后直接显示该功能，不再保留可见的多标签卡片。
2. 页面、书籍、设置等程序内跳转仍能直接打开目标视图；现有页面状态持久化可以内部兼容，但不得再次渲染标签栏。
3. 删除所有位于中文主标题上方的英文眉题，包括但不限于问答页的 `CONVERSATIONS`、`EVIDENCE FIRST`、`AUDIT TRAIL` 以及其他页面使用 `.eyebrow` 的英文标签。
4. 智能问答页包含自己的“本轮证据”栏，因此进入智能问答时默认折叠全局研究脉络，避免两个右栏同时挤压中央问答区域。
5. 全局研究脉络折叠后不再悬浮覆盖工作区；应显示为最右侧固定窄栏，展开按钮位于该窄栏顶部。
6. 用户在智能问答页主动展开研究脉络后允许查看；离开并再次进入智能问答时重新折叠。
7. 展开状态的刷新与折叠控件继续位于研究脉络右栏标题区，功能保持不变。
8. 调整主工作区/问答页高度，使移除标签栏后内容从顶部自然开始，不出现空白占位。
9. 单元测试仅在全部代码完成后运行一轮，不做重复复测；随后各运行一轮 build、verify、release GUI E2E 和安装版 GUI E2E。
10. 构建并安装新的 Windows 客户端，启动确认可响应；Git 提交不得包含两个既有 raw 未跟踪目录。

## Acceptance Criteria

- [ ] 页面顶部不存在工作区标签栏或卡片标签，侧栏点击后立即切换唯一主视图。
- [ ] 客户端 UI 中不存在 `.eyebrow` 英文眉题，问答三个分栏只显示中文标题。
- [ ] 进入智能问答时全局研究脉络折叠，中央问答和本轮证据栏完整可见。
- [ ] 折叠态是最右侧固定窄栏而非覆盖工作区的浮动按钮。
- [ ] 展开、刷新、再次折叠研究脉络均正常。
- [ ] 页面/书籍/设置等内部导航没有因移除标签栏失效。
- [ ] 单元测试只执行一轮且通过；build、verify、源码版与安装版 GUI E2E 通过。
- [ ] 最新 NSIS 已安装，客户端窗口正常响应。
- [ ] Git 已保存任务代码、归档和日志，raw 未跟踪目录未提交。

## Notes

- 不删除问答页自身的“本轮证据”功能；它与全局研究脉络用途不同。
- 不重写后端、检索或会话状态，仅调整导航表现与布局。
