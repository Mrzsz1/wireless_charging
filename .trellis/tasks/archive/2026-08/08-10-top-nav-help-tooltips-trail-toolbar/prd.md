# 顶部导航、延迟帮助注释与研究脉络工具栏重设计

## Goal

让客户端的高频全局入口与说明信息更接近 Codex 桌面端：设置和帮助固定在顶部；设置页减少常驻说明文字；研究脉络面板使用更明确、紧凑的工具控件。

## Requirements

1. 从左侧边栏底部移除“设置”“帮助”，并将二者放入顶部标题栏，保持在侧栏折叠与展开状态下都可用。
2. 顶部入口使用轻量文字菜单样式，当前页面有可识别的激活态；不得破坏窗口拖动区与最小化、最大化、关闭按钮。
3. 设置页的页面级说明和各设置分区标题说明改为问号帮助图标，不再常驻占用纵向空间。
4. 鼠标在问号图标上连续悬停满 1000ms 后显示原说明文字；提前移开不显示；键盘聚焦和点击也能获取说明；提示具备可访问语义。
5. 字段值、状态、错误、操作后果等必要信息保留，不把关键反馈隐藏进提示框。
6. 研究脉络刷新改为带文本的紧凑胶囊按钮，折叠改为面板语义图标；折叠后的恢复按钮使用同一图标语言并放在工作区右上侧。
7. 保留现有数据加载、刷新、折叠、恢复、设置导航和帮助导航行为。
8. 不新增或删除单元测试；更新现有 GUI E2E 覆盖新位置、延迟提示和面板控件。
9. 完成前构建 release、运行严格 GUI E2E、安装最新 NSIS 包并对安装版本复验。
10. Git 提交不得包含两个既有的 `raw/inbox/auto-discovered/runs/search-*` 未跟踪目录。

## Acceptance Criteria

- [x] 左侧边栏不再出现设置/帮助底部区域，顶部标题栏可进入设置和帮助。
- [x] 标题栏空白区域仍可拖动窗口，Windows 三个窗口按钮仍可用。
- [x] 设置页页面标题和五个分区标题旁显示统一问号图标，说明文字不再常驻显示。
- [x] 问号悬停不足 1 秒不显示提示，达到 1 秒显示对应原说明，离开后关闭。
- [x] 研究脉络显示“刷新”胶囊与面板收起图标；折叠后显示一致的恢复图标按钮。
- [x] 左侧“我的空间”高度拖动仍正常，移除 footer 后最大高度计算无异常。
- [x] 前端 build、现有测试、严格 GUI E2E 和安装版 GUI E2E 均通过。
- [x] 最新客户端已重新打包并安装，应用可正常启动显示。
- [x] 改动已单独提交到 Git，原始文献运行目录未被提交。

## Notes

- 保持现有浅天蓝色视觉系统和 Lucide 图标体系，不引入新依赖。
- “说明文字”仅指页面/卡片标题的概览性副文案；字段帮助、状态诊断和安全信息继续直接展示。
