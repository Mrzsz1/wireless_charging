# 修复桌面窗口只在任务栏预览但正文不可见

## 目标

修复 Windows 客户端启动后只出现任务栏缩略图、主窗口位于屏幕外而不能正常显示的问题；同时关闭窗口状态持久化的 DPI/多显示器边界缺陷和安装冒烟残留进程问题，重新生成可验证的 0.7.2 EXE、MSI 与 NSIS 安装包。

## 已确认事实

- 当前唯一显示器工作区为 `{x:0,y:0,width:2048,height:1104}`，故障进程窗口矩形为 `{left:-2858,top:381,right:-708,bottom:1589}`，窗口可见标志为 true，但矩形与任何显示器均不相交。
- 故障进程来自上一轮严格安装测试目录：`apps/desktop/.tmp/p5-installer-verify/app.exe`；安装测试结束后进程仍存活。
- `apps/desktop/src/App.tsx:244-245` 使用 `innerSize()` 与 `outerPosition()` 保存物理像素；`App.tsx:251-252` 却使用 `LogicalSize`/`LogicalPosition` 恢复，存在 DPI 单位不一致。
- 现有恢复逻辑只检查宽高下限，不检查数值合法性、显示器变更、工作区相交、最小化/隐藏状态，也没有启动时 `show`/`unminimize`/`setFocus` 兜底。
- `apps/desktop/scripts/smoke-installer.mjs` 使用带超时的同步启动探测，但未确保被测应用在卸载前退出。

## 需求

### R1：窗口放置必须使用统一坐标单位

- 持久化与恢复统一使用物理像素，避免高 DPI 下把物理值再次按逻辑像素缩放。
- 新增独立窗口状态版本；兼容读取旧 `desktop.window-state.v2`，成功恢复后写入新版本键。
- 非有限数、负尺寸、过小尺寸和明显损坏的状态直接进入安全回退。

### R2：启动窗口必须位于当前显示器工作区

- 使用当前可用显示器工作区校验恢复矩形。
- 保存位置仍与任一工作区相交时，将尺寸和位置限制在对应工作区内。
- 保存位置与所有显示器均不相交时，在主显示器工作区居中，并清除无效位置影响。
- 显示器减少、分辨率改变、任务栏工作区改变和负坐标多显示器布局均需正确处理。

### R3：窗口状态恢复与保存必须稳定

- 启动恢复完成后执行 `unminimize`、`show` 和 `setFocus`，确保任务栏点击和首次启动均可见。
- 最大化时只记录最大化标志，保留最后一次正常窗口矩形；最小化时不覆盖正常矩形。
- move/resize 高频事件采用防抖或串行保存，避免旧异步结果覆盖新状态。
- 初始窗口配置启用居中，作为前端恢复逻辑执行前的第一层兜底。

### R4：安装冒烟不得留下孤儿进程

- 启动探测后必须显式关闭/终止被测应用，并等待进程退出，再执行卸载。
- 严格模式在应用仍存活、卸载器缺失、卸载失败或安装目录仍存在时返回失败。
- 冒烟测试不得复用或影响用户当前安装目录。

### R5：权限、测试与发布

- Tauri capability 明确包含恢复流程需要的 show、unminimize、unmaximize、set-focus 等权限。
- 为窗口矩形迁移、单屏越界、多屏负坐标、分辨率缩小、非法状态增加 Node 单元测试。
- 扩展结构门禁与 GUI strict：启动后窗口矩形必须与至少一个显示器工作区相交。
- 版本更新为 0.7.2，保留 0.7.1 产物用于回退。
