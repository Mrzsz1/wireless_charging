# 语义模型下载进度

## Goal

在设置页“下载/修复”按钮右侧显示真实下载进度，让用户明确当前阶段、文件、字节进度、百分比和速度，避免长时间只有旋转图标。

## Requirements

- 后端必须基于实际读取/写入字节推送进度，禁止模拟定时进度。
- ONNX Runtime、量化模型和四个 tokenizer/config 文件都必须产生阶段事件。
- 事件包含阶段、文件标签、已完成字节、总字节、百分比、字节/秒、状态和可读消息。
- 已缓存文件产生 skipped/complete 事件，不重复下载。
- 推理加载与 384 维探针分别展示 verifying 阶段。
- Tauri 使用 Channel 流式传递事件，最终命令结果仍返回 `SemanticDeploymentStatus`。
- 前端在“下载/修复”按钮右侧显示紧凑进度区；窄屏换行，不扩大整个设置卡片高度。
- 失败时保留最后真实进度并显示错误；重试从新的事件序列开始。

## Acceptance Criteria

- [x] 下载模型时可以看到当前文件、真实字节、百分比和速度变化。
- [x] 已缓存资源不会显示虚假下载过程。
- [x] 下载结束后显示验证阶段，最终状态与部署检查一致。
- [x] 进度区域位于下载/修复按钮右侧并符合现有 UI 风格。
- [x] Rust、前端全测、前端构建及 Tauri release 编译通过。

## Out of Scope

- 暂停、取消或限速下载。
- 多个并行模型下载任务。
